Редактор расшифровок

Выберите тему и ответ, чтобы изменить текст, который увидит участница.

Как опубликовать изменения

Скачайте index.html. Войдите в GitHub под аккаунтом владельца и откройте загрузку в папку теста. Выберите скачанный файл с именем index.html и нажмите Commit changes. После обновления сайта изменения увидят все участники.
